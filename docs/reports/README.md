# Verification reports and reviews

immutable evidence: they record what was observed at that time and are not current
setup guidance. Use the [documentation map](../README.md) for current guides.

The files were moved here from `docs/` without content changes during the
documentation reorganisation after v0.10.0. Relative links inside them refer to the
previous flat layout; the original layout remains available in the corresponding
release tag. Current locations: guides are in [`../guides/`](../guides/),
contracts in [`../reference/`](../reference/), upgrade procedures in
[`../upgrades/`](../upgrades/).
